# 👨‍💻 Guia Rápido Git & GitHub

Repositório pessoal com comandos básicos de Git e GitHub para iniciantes.

---

## 🚀 Configuração inicial

```bash
git config --global user.name "Seu Nome"
git config --global user.email "seuemail@email.com"
📂 Criar repositório
git init
📥 Clonar repositório
git clone https://github.com/seuusuario/repositorio.git
📌 Verificar status
git status
➕ Adicionar arquivos
git add .

ou

git add nome-do-arquivo
💾 Criar commit
git commit -m "mensagem do commit"
📤 Enviar para GitHub
git push origin main
📥 Atualizar projeto local
git pull origin main
🌿 Trabalhar com branches

Criar branch:

git checkout -b nova-branch

Trocar branch:

git checkout main
🔍 Ver histórico
git log
🧠 Objetivo

Aprender Git e GitHub de forma simples e prática.
